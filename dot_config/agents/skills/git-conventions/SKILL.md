---
name: git-conventions
description: Git operation guidelines, commit messages, and branching strategy
---

- Work based on the `main` branch unless otherwise specified for a special branch strategy
- Limit each commit to a single change
- Always obtain user approval before committing (do not commit without permission)
- Format commit messages according to existing conventions:
  - If no existing conventions exist, use the conventional commit format
    - The first line should contain a brief summary
    - Subsequent lines should list each change in detail
- Only perform push operations when explicitly instructed by the user
